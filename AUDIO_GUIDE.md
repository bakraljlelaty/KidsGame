# Audio Guide

All shipped audio is **original, programmatically synthesized placeholder WAV** (soft sine-based
chimes) generated by `tool/gen_audio.py`. Real recordings replace the placeholders **1:1 by file
name** — no code changes.

## AudioManager: channels and settings

`lib/core/audio/audio_manager.dart` is the central audio service. Three independent channels:

| Channel | Player(s) | Volume | Behaviour |
|---|---|---|---|
| Music | 1 looping player | 0.35 | `playMusic(MusicTrack)` loops; pauses/resumes with app lifecycle |
| Voice | 1 player | 1.0 | `playInstruction(VoiceInstruction)` stops any line already speaking — voices never overlap |
| Effects | pool of 3 players (round-robin) | 0.85 | `playEffect(SoundEffect)`; overlapping effects allowed |

Interplay with parent settings (`AudioManager.applySettings`, re-applied automatically whenever
`SettingsController` changes):

- `settingsMusic` off → music pauses immediately; turning it back on resumes the current track.
- `settingsSoundEffects` off → `playEffect` becomes a no-op.
- `settingsVoice` off → `playInstruction` becomes a no-op.
- App language → which `assets/audio/voices/<lang>/` folder voice clips load from.

Robustness rules baked in: the manager respects the device silent switch
(`respectSilence: true`); if `init()` was never called or a platform player fails (emulator
without sound), every call is a **safe no-op** — audio must never break the child's app. Games
talk to the `GameAudio` interface only (`playEffect` / `playInstruction`); tests inject
`NoopGameAudio`.

## Voice instructions: id → file mapping

Spoken prompts are identified by the `VoiceInstruction` enum
(`lib/core/audio/voice_catalog.dart`) and resolved by `VoiceCatalog.assetPath` to:

```
assets/audio/voices/<lang>/<snake_case_id>.wav
```

The file id is the enum name converted to snake_case: `feedRabbit` →
`assets/audio/voices/en/feed_rabbit.wav` (and `.../ar/feed_rabbit.wav`). An unsupported language
code falls back to the first entry of `VoiceCatalog.supportedLanguages` (`en`). Display text for
parents lives in the ARB files, deliberately **separate** from these audio ids.

|---|---|

| Counting | `count_one`, `count_two`, `count_three` |
| Feed the Animals | `feed_intro`, `feed_rabbit`, `feed_cow`, `feed_monkey` |
| Bubble Pop | `bubble_intro`, `pop_blue`, `pop_yellow`, `pop_red`, `pop_green`, `pop_fish`, `pop_star`, `pop_heart`, `pop_then_next` |

## Regenerating placeholder audio

From the repo root:

```bash
python3 tool/gen_audio.py
```

The script (re)writes every effect, both music loops, and one placeholder clip per
`VoiceInstruction` per language. It **parses the enum straight out of
`lib/core/audio/voice_catalog.dart`**, so after adding instruction ids just rerun it and the new
files exist — no list to maintain. Placeholder voice clips are distinct little tone patterns per
id so testers can tell prompts apart; they are obviously not speech.

## Replacing placeholders with real recordings

- **Format:** WAV (the current pipeline is 22 050 Hz mono 16-bit; any WAV audioplayers can decode
  works). Keep files small — they ship inside the APK/AAB.
- **File names must match exactly** (same snake_case ids, same folders:
  `assets/audio/voices/en/…`, `assets/audio/voices/ar/…`, `assets/audio/effects/…`,
  `assets/audio/music/…`). Drop the files in, rebuild, done. New *folders* (a new language) also
  need an `assets:` entry in `pubspec.yaml`.
- **Voice direction:** a calm, warm, unhurried adult voice; short sentences; friendly but not
  hyper. No shouting, no sarcasm, nothing startling. Leave a beat of silence at the ends. Record
  every id in every supported language, and keep loudness consistent across clips (the voice
  channel plays at full volume over quiet music).
- **Licensing:** every replacement recording and every piece of music must be original or
  licensed for commercial use in a children's app, with voice-actor releases and license records
  kept. No unlicensed samples, no sound-alikes of trademarked jingles.

## Music loops

`MusicTrack` (`lib/core/audio/sound_effects.dart`) → `assets/audio/music/<id>.wav`:

| Id | File | Used for |
|---|---|---|
| `calm` | `calm_loop.wav` | Day-time background (home, map, games) |
| `lullaby` | `lullaby_loop.wav` | Sleepy screen / session wind-down |

The music player loops whatever it is given (`ReleaseMode.loop`), so author replacement loops to
be seamless (matching start/end, no clicks) and *quiet* — they sit under voice at 0.35 volume.

## Sound effects

`SoundEffect` (`lib/core/audio/sound_effects.dart`) → `assets/audio/effects/<id>.wav`:

| Id | File | Typical use |
|---|---|---|
| `pop` | `pop.wav` | Bubble pops, small pickups |
| `chimeSuccess` | `chime_success.wav` | A correct step |
| `chimeSoft` | `chime_soft.wav` | Gentle neutral feedback |
| `boingSoft` | `boing_soft.wav` | Wrong-attempt bounce-back (soft, never punitive) |
| `waterSplash` | `water_splash.wav` | Muddy Pig Bath water play |
| `chew` | `chew.wav` | Animals eating (Feed the Animals) |
| `sparkle` | `sparkle.wav` | Sparkle bursts, sticker moments |
| `yawn` | `yawn.wav` | Sleepy Milo |
| `slide` | `slide.wav` | Items sliding/snapping into place |
| `ding` | `ding.wav` | Small confirmations |
| `celebrate` | `celebrate.wav` | Activity completion fanfare (still gentle) |
| `sessionReminder` | `session_reminder.wav` | Soft cue ~1 minute before session end |
| `nightCalm` | `night_calm.wav` | Sleepy screen ambience |

All effects are preloaded at startup (`AudioManager.preload`) together with the music loops, so
keep them short. When adding an effect: add the enum value with its `fileId`, add a matching
generator entry in `tool/gen_audio.py` (or drop in a real file), and rerun the script.
