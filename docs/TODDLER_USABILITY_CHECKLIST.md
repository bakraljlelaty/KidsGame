# Toddler Usability Checklist

A manual pass on a **real device**, with the **release build** where possible — ideally while
observing a child in the target age range (2–3) playing naturally. Run it for every mini-game and
once for the app as a whole; repeat after any change to interactions, audio, pacing, or layout.

Answer every question honestly; each "No" (or "Partly") gets a note and a follow-up issue.
