# Voice Recording Script — Little Wonder Academy

One row per clip. Record **each clip as its own file**, named
exactly `<clip id>.wav` (English takes en/, Arabic takes ar/),
then run `python3 tool/import_recordings.py <folder>`.

**Studio notes**

- Narrator: warm, unhurried, smiling — speaking to a 2–6 year
  old. Never sharp, never loud; celebrations are gentle joy,
  not shouting.
- Format: WAV, 44.1 kHz or higher, mono, quiet room. Leave
  ~0.2 s of silence at both ends (the importer trims).
- Keep energy and microphone distance consistent across the
  whole session; the counting words and color/shape/name words
  should feel like one matched family.
- Arabic is written fully vocalized (مُشَكَّل) — please follow
  the diacritics; Modern Standard Arabic with a soft, friendly
  delivery.
